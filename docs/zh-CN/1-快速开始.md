# 1-快速开始

本指南带你完成 Snow App 的安装、首次运行、基础配置，并完成与 AI 的
第一次对话。

## 1. 安装

### Windows

1. 下载安装包 `Snow-App-Setup-<版本>.exe`；
2. 双击运行，按向导完成安装（可选择安装目录）；
3. 从开始菜单或桌面快捷方式启动 Snow App。

> 也提供便携版 `Snow-App-<版本>.exe`，免安装直接运行。

### macOS

1. 下载 `Snow-App-<版本>-<架构>.dmg`，拖入 Applications；
2. 如果打开时提示"已损坏"或"无法打开"，在终端执行：

```bash
sudo xattr -rd com.apple.quarantine /Applications/Snow\ App.app
```

### Linux

下载对应发行版的安装包（AppImage / deb），按系统方式安装。

## 2. 首次运行

启动后界面包含三个区域：

| 区域 | 内容 |
| --- | --- |
| **侧边栏** | 项目/工作区目录（本地与 SSH）、会话列表、备忘录、定时任务、设置入口 |
| **主区域** | AI 对话、终端、Git、浏览器、代码库等视图 |
| **右侧面板** | 文件阅读器（Markdown 渲染预览/图片/Office 文档）、Diff 预览、Git 面板，可多标签 |

各区域的功能详细介绍见 [2-使用指南/10-使用聊天与AI助手](2-使用指南/10-使用聊天与AI助手.md)。

## 3. 基础配置

首次使用建议依次完成：

1. **配置 API 密钥**：设置 → API 设置，填入你的模型服务商密钥；
2. **添加工作区目录**：侧边栏 → 添加目录（本地或 SSH）；
3. **（可选）配置代理**：设置 → 代理与浏览器，如网络需要代理；
4. **（可选）配置 MCP 服务器**：设置 → MCP 设置，添加外部工具服务。

各配置项的详细步骤见对应的使用指南：

## 4. 第一次对话

配置好 API 密钥并选择工作区目录后，在主区域输入框发送：

```text
你好！请介绍一下当前工作区目录的结构，并告诉我里面最大的文件是什么
```

你会看到：

1. AI **流式**返回文字；
2. 需要时自动调用工具（列出目录、读取文件大小等），每个工具调用
   以卡片形式实时展示；
3. 最终汇总回答，并可在回复上执行复制、查看原始 Markdown、回滚等操作。

**进阶示例**：粘贴一张图片并发送"帮我看看这张图里有什么"（需视觉模型）；
或输入 `/` 打开命令面板，试试 `/file-changes`（查看 AI 改过的文件与 diff）。

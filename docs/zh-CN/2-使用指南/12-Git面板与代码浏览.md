# 12-Git面板与代码浏览

本文介绍三类代码相关功能：**Git 面板**（仓库管理与 Diff 查看）、
**右侧文件阅读器**（多标签文件浏览与 Markdown 预览）、**代码库面板**
（语义搜索与 3D 关系球体）。

## 1. Git 面板

### 1.1 打开与仓库选择

- 右侧面板的 **Git tab** 打开 Git 面板；面板会自动发现工作区中的
  Git 仓库；
- **仓库选择器**：切换当前操作的仓库，右键可复制仓库路径、在
  文件管理器中显示、在终端中打开；
- 支持 `ssh://` **远程仓库**（见 [11-终端与SSH远程管理](11-终端与SSH远程管理.md)）。

### 1.2 变更与 Diff

| 区域 | 说明 |
| --- | --- |
| 变更列表 | 工作区/暂存区的文件变更列表，显示新增/修改/删除状态 |
| Diff 查看 | 点击文件在右侧打开 **Diff 预览**（逐行对比，增删着色） |
| 文件操作 | 文件条目右键：在终端中打开、在文件管理器中显示、打开文件阅读器 |

### 1.3 提交与同步

- 输入提交信息后提交；
- 拉取 / 推送 / 刷新状态；
- 远程仓库状态自动轮询刷新（每 10 秒，见 SSH 文档）。

> **AI 协作**：AI 修改文件后可通过聊天中的 `/file-changes` 命令查看
> 本轮变更；在 Git 面板中同样可以看到并审阅。提交等操作也可直接
> 让 AI 在终端/工作区中执行 git 命令。

## 2. 右侧文件阅读器

右侧面板是**多标签**的文件阅读器，支持：

| 文件类型 | 支持 |
| --- | --- |
| 文本/代码 | 语法高亮、行号、全文搜索（搜索自动定位高亮） |
| Markdown（`.md`） | **渲染预览**（标题/表格/代码块/公式/图表）+ 源码视图切换；表格宽时可横向滚动；`md` 内相对链接点击可在新标签打开对应文件 |
| 图片 | 预览（可放大）；SVG 支持图像/代码双视图 |
| Office 文档 | PDF / Word / Excel / CSV 等直接读取文本内容 |
| 二进制 | 显示"二进制文件"占位 |

打开方式：点击侧边栏文件、聊天中文件链接、Git diff 文件、`@` 引用等。
标签页右键可新建终端/浏览器/关闭；文件右键可"在终端中打开"、
"在文件管理器中显示"等。

### Markdown 预览小贴士

- **宽表格**：自动横向滚动，不会被截断；
- **公式**：`$...$` 行内、`$$...$$` 块级（KaTeX）；
- **图表**：``` ```mermaid ``` ``` 代码块渲染为可交互图表（可切换
  代码/图、下载为图片）；
- **切换视图**：工具栏"渲染预览 / 源码"按钮切换；编辑自动切回源码。

## 3. 代码库面板与语义搜索

### 3.1 启用

代码库索引在 **设置 → 代码库设置**（`app-control-openSettings
page=codebase-settings`）中启用并配置嵌入模型；首次索引可能需要数分钟。
启用后：

- 聊天输入框的 `/codebase` 命令打开项目代码库面板；
- AI 获得 `codebase-search` 工具（见
  [7-代码库索引与代码诊断](7-代码库索引与代码诊断.md)）。

### 3.2 3D 相似度球体

代码库面板包含一个 **3D 球体视图**：每个文件是一个节点，节点距离
反映嵌入向量的相似度，可拖拽旋转、缩放，快速感知文件聚类与依赖
关系（布局计算在 Rust 后台线程完成，不阻塞 UI）。

### 3.3 自然语言文件搜索

在聊天输入框输入 `@?<query>` 可发起**自然语言文件搜索**：AI 自动组合
grep / filesystem 工具定位相关文件，并实时展示搜索进度与结果。

### 3.4 代码库索引面板（输入框旁）

- **扫描预览**：索引前显示将扫描的文件数/大小，避免误索引大目录；
- **索引统计**：文件数、嵌入进度；未索引时可一键开始/重建；
- **嵌入进度**：实时显示向量化进度，完成后可立即使用语义搜索。

## 4. 常见问题

| 症状 | 原因与处理 |
| --- | --- |
| Git 面板看不到仓库 | 确认工作区目录下存在 `.git`；远程仓库需先连接 SSH |
| 语义搜索不可用 | 代码库索引未启用或未完成；检查嵌入模型配置 |
| 3D 球体卡顿 | 布局已移至 Rust 后台线程；超大仓库可先用 `fileGlob` 限定索引范围 |
| 预览与源码不一致 | Markdown 预览基于渲染器；以源码视图为准 |

# 4-配置代理与网络

Snow App 的代理设置同时作用于应用会话网络请求、web 搜索与内置浏览器。
本文介绍如何配置代理、搜索引擎与内置浏览器。

## 1. 认识配置入口

| 入口 | 说明 |
| --- | --- |
| 设置 → 代理与浏览器（设置页 id：`proxy-browser-settings`） | 图形界面：代理、搜索引擎、内置浏览器配置 |
| `~/.snow/proxy-config.json` | 可与应用同步的配置文件 |

配置值保存在应用系统设置中，可与 `~/.snow/proxy-config.json` 同步。

## 2. 配置代理

| 字段 | 说明 |
| --- | --- |
| `enabled` | 启用开关，是否使用代理 |
| `host` | 代理主机，如 `127.0.0.1` |
| `port` | 代理端口，如 `7890` |

## 3. 配置搜索引擎

| 字段 | 说明 |
| --- | --- |
| `searchEngine` | 搜索引擎，如 `bing`、`duckduckgo` |

该设置影响 `websearch` 工具的搜索结果来源。

## 4. 配置内置浏览器

| 字段 | 说明 |
| --- | --- |
| `browserPath` | 浏览器可执行文件路径；留空时自动检测 Chrome / Edge / Chromium，也可点击 Browse 手动选择 |
| `browserDebugPort` | 浏览器调试端口，如 `9222` |

调试端口用于内置浏览器面板的连接；端口被占用时面板可能无法打开。

## 5. 生效范围

- **应用会话代理**：网络请求、更新检查；
- **web 搜索**：`websearch` 工具；
- **内置浏览器面板**：嵌入式浏览器实例。

## 6. 常见问题

| 症状 | 原因与处理 |
| --- | --- |
| 搜索失败 | 检查代理是否启用、`host`/`port` 是否正确 |
| 浏览器面板打不开 | 检查 `browserPath` 是否正确，或调试端口被占用 |
| 修改后没生效 | 确认已保存（输入框失焦时自动保存） |

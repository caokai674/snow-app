# 10-使用聊天与AI助手

Snow App 的核心是与 AI 的对话式协作：AI 不仅回复文本，还能通过内置
工具读写文件、执行命令、搜索网络、浏览网页、生成图片，并在对话中
实时展示每一步过程。本文介绍界面布局、对话方法与常用交互。

## 1. 界面布局总览

```
┌──────────────┬──────────────────────────────┬──────────────┐
│   侧边栏     │          主区域              │  右侧面板     │
│  ・项目/目录  │  ・AI 对话（聊天）            │  ・文件阅读器  │
│  ・会话列表   │  ・终端 / SSH / Git / 浏览器  │  ・MD 预览    │
│  ・备忘录     │  ・定时任务                   │  ・Diff 预览   │
│  ・设置入口   │  ・输入框（/命令、@文件、图片）│  ・Git 面板    │
└──────────────┴──────────────────────────────┴──────────────┘
```

| 区域 | 内容 |
| --- | --- |
| 侧边栏 | 项目/工作区目录（本地与 SSH）、会话列表、备忘录入口、定时任务入口、设置入口 |
| 主区域 | 当前视图：AI 对话、终端、Git、浏览器、代码库等 |
| 右侧面板 | 文件阅读器（支持 Markdown 渲染预览、图片、Office 文档）、Diff 预览、Git 面板，可多标签 |
| 顶部栏 | 视图切换、API 档案切换（快捷键 `Alt+P` / macOS `Ctrl+P`）、设置等 |

## 2. 开始对话

1. 在侧边栏选择或新建一个**会话**（对话按项目/目录组织）；
2. 在输入框输入内容，回车或点击发送；
3. AI 以**流式**方式逐字返回；需要工具时会自动调用并在对话中展示。

**第一个示例**：在会话中发送

```text
帮我看看当前项目里有哪些 Python 文件，并总结每个文件的用途
```

AI 会依次调用 `grep-search` 搜索 `*.py`、`filesystem-read` 读取文件、
`codelens-file_outline` 分析结构，最后汇总回答——每一步都以卡片形式
展示在对话中（见下文"工具调用可视化"）。

> **切换模型/档案**：输入框上方或顶部栏可切换 API 档案（Profile）；
> 系统提示词、思考强度等可在输入框附近调整。配置见
> [3-配置API密钥与模型](3-配置API密钥与模型.md)。

### 2.1 会话管理

会话列表中的每一条会话都可以通过 **hover 行尾的「⋯」按钮** 或
**右键点击会话行** 打开操作菜单：

| 操作 | 说明 |
| --- | --- |
| 置顶 / 取消置顶 | 将会话固定到列表顶部的「置顶」分组 |
| 重命名 | 修改会话显示名称；也可**双击标题**直接进入编辑 |
| 图标 | 为会话设置 Emoji 图标 |
| 导出 | 导出为 Markdown / HTML / JSON / CSV |
| 多选 | 进入多选模式，批量勾选会话 |
| 删除 | 删除会话（需二次确认） |

> **右键菜单**：在会话行上点击鼠标右键，会在**光标位置**弹出与
> 「⋯」按钮完全相同的菜单；在重命名编辑中或多选模式下不拦截右键，
> 保留系统菜单（如输入框的复制/粘贴）。

## 3. 输入框功能

### 3.1 斜杠命令面板（`/`）

输入 `/` 打开命令面板，可过滤选择：

| 命令 | 功能 |
| --- | --- |
| `/new`（新对话） | 清空当前会话，开始新对话 |
| `/compact`（压缩） | 压缩上下文并生成交接摘要（见下文"上下文压缩"） |
| `/file-changes`（文件变更） | 打开文件变更面板：查看/选择 AI 已修改的文件与 diff |
| `/mcp` | 打开 MCP 服务器管理面板 |
| `/role` | 选择角色/系统提示词（需已选择项目） |
| `/sensitive-commands` | 配置项目级敏感命令（需已选择项目） |
| `/skills` | 查看与启用技能（需已选择项目） |
| `/codebase` | 打开代码库索引面板（需已选择项目） |

> 部分命令在 AI 运行中禁用（避免打断执行）。

### 3.2 引用文件与图片（`@`）

- 输入 `@` 弹出**文件提及**面板：搜索并选择工作区文件，插入后 AI 会自动
  读取该文件；
- 也可以直接**粘贴图片**（剪贴板或拖拽）：图片以缩略图 chip 显示在输入框，
  悬停可预览、点击可放大；发送后 AI 通过视觉模型理解图片，也可用于
  **图生图/编辑**（见 [9-图像生成](9-图像生成.md)）。
  主模型不支持视觉时，图片会先经外挂视觉模型文本化为文字描述，同时附带
  `[Reference image #N ...]` 引用块（仅含 upload 目录相对路径）——AI 做
  图生图时按引用**读取原始图片**，不会被降级为文生图。

### 3.3 其他

| 能力 | 说明 |
| --- | --- |
| 手动选择模型 | 输入框附近可临时指定本次使用的模型 |
| 思考强度 | 调节推理强度（如 `minimal`/`high`）；AI 的思考过程可展开查看 |
| 多行输入 | `Shift+Enter` 换行，`Enter` 发送 |
| 草稿自动保存 | 输入内容（含图片 chip）**按会话自动保存**：切换会话、新建会话或会话历史加载期间都不会丢失，切回该会话自动恢复；发送成功后自动清除 |

## 4. AI 回复与消息操作

每条 AI 回复右上角提供操作：

| 操作 | 说明 |
| --- | --- |
| 复制 | 复制回复内容 |
| 复制为 Markdown | 复制为 Markdown 源码 |
| 复制为纯文本 | 复制去掉格式的纯文本 |
| 查看原始 Markdown | 切换显示渲染结果 / Markdown 源码 |
| 回滚 | 将会话回滚到该条消息之前（见下文） |
| 停止 | 生成中点击可中断输出（"正在停止..."） |

Markdown 渲染支持：标题、表格（宽表可横向滚动）、代码块（带语言标签与
复制按钮）、KaTeX 公式（`$...$` / `$$...$$`）、Mermaid 图表（可切换
代码/图查看、下载为图片）、任务列表、引用块等。

## 5. 工具调用可视化

AI 调用工具时，对话中会展示对应卡片，随时可查看过程与结果：

| 工具类别 | 展示内容 |
| --- | --- |
| `bash-terminal-execute` | 执行的命令、输出流（stdout/stderr 分色）、交互式输入 |
| `filesystem-*` | 读取的文件内容/图片预览、编辑的 diff 摘要（可打开右侧 Diff 预览） |
| `grep-search` / `websearch-*` | 搜索条件与命中结果列表 |
| `browser-*` | 打开的页面、截图、控制台/网络信息 |
| `todo-todo-manage` | 任务清单增删改（可展开查看） |
| `imagegen-generate` | 生成的图片（含流式预览过程） |
| `sub-agents-activate` | 子代理执行详情（提示词、步骤、结果） |
| `codelens-*` / `codebase-search` | 诊断结果、语义搜索结果 |

> 文件变更后，可通过 `/file-changes` 命令集中查看本轮修改了哪些文件、
> 每个文件的 diff，点击可打开右侧面板的完整 Diff 预览。

## 6. 回滚（Rollback）

AI 修改文件后如果结果不理想，可将会话**回滚**到某条消息之前：

1. 在目标 AI 消息上点击 **回滚**；
2. 弹出确认框显示该步骤涉及的变更（新增/修改/删除的文件列表）；
3. 选择范围：
   - **仅回滚会话**：只删除该消息之后的对话内容；
   - **回滚会话和文件**：同时恢复文件到回滚点（基于 checkpoint 快照），
     并删除对应 TODO 项。

> 回滚依赖消息级 checkpoint；跨文件变更可在确认框中"查看变更"预览
> Diff 后再决定。

## 7. 上下文压缩（Compact）

长对话会占用大量上下文。点击 **压缩**（或 `/compact`）：

1. AI 自动把当前对话总结为**上下文交接文档**（摘要）；
2. 对话被替换为摘要 + 后续内容，上下文占用大幅降低；
3. 摘要可展开/收起查看。

> 压缩不可逆，建议在确认摘要完整后继续对话。也可通过 Hooks 的
> `beforeCompress` 在压缩前执行自定义逻辑（见
> [5-配置Hooks与子代理](5-配置Hooks与子代理.md)）。

## 8. 定时任务

侧边栏的**定时任务**入口（或 AI 调用 `app-control-createScheduledTask`）
可创建自动化任务：到点自动把预设提示词发送给 AI 执行。

| 配置项 | 说明 |
| --- | --- |
| 名称 / 提示词 | 任务说明与要 AI 执行的内容 |
| 任务类型 | 单次（指定开始时间）或循环 |
| 循环方式 | 固定间隔（分钟/小时）或每天固定时刻 |
| 操作 | 立即运行、暂停/恢复、删除、全部清除 |

> 任务仅在**应用运行期间**生效，退出应用后清除（不会持久化）。

## 9. 备忘录

侧边栏的备忘录入口可快速记录想法，支持创建/编辑/删除；AI 也可通过
`app-control-createMemo` 工具在对话中为你创建备忘录。

## 10. 常见问题

| 症状 | 原因与处理 |
| --- | --- |
| AI 没有可用工具 | 检查 API 档案与模型配置；部分工具按需暴露（如生图需先配置，见 [9-图像生成](9-图像生成.md)） |
| 输出中断 | 点击"停止"后不会恢复；重新发送或使用回滚 |
| 图片无法理解 | 确认当前档案配置了视觉模型（见 [3-配置API密钥与模型](3-配置API密钥与模型.md)） |
| 表格/公式显示异常 | 宽表格可横向滚动；公式需用 `$...$` 语法 |
| 任务清单丢失 | 回滚会同时删除对应 TODO 项（确认框有提示） |

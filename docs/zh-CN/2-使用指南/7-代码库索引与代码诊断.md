# 7-代码库索引与代码诊断（Codebase Index & Code Diagnostics）

Snow App 提供代码库语义搜索（`codebase` 服务器）与代码符号诊断
（`codelens` 服务器）两类内置能力，帮助 Agent 快速理解、定位和检查
代码。

## 1. 代码库语义搜索（codebase）

### 1.1 启用与索引

`codebase-search` 仅在**项目启用了代码库索引且已建立索引后**暴露。
在 **设置 → 代码库设置**（`app-control-openSettings page=codebase-settings`）
启用对应项目的索引，并配置嵌入模型（见 `settings.json` 的 `codebase`
字段，`3-配置文件字段参考` 有结构说明）。首次索引可能需要数分钟。

### 1.2 工具

| 工具 | 用途 |
| --- | --- |
| `codebase-search` | 基于嵌入索引的语义搜索 |

参数：`pattern`（查询文本）、`path`（限定目录）、`fileGlob`（限定文件
类型）、`maxResults`（结果数上限）。

### 1.3 使用示例

```text
codebase-search pattern="如何处理配置文件反斜杠转义" path="src/main" maxResults=10
→ 按语义相似度返回相关代码片段

codebase-search pattern="retry logic" fileGlob="*.rs" maxResults=5
→ 只搜 Rust 文件
```

### 1.4 与 grep 的取舍

| 场景 | 用哪个 |
| --- | --- |
| 关键词精确匹配、正则、按路径限定 | `grep-search`（更快更准） |
| 语义/意图查询（"查找处理登录的逻辑"） | `codebase-search`（理解含义） |

## 2. 代码诊断与符号定位（codelens）

`codelens` 服务器基于语义分析（oxc / tree-sitter 等）提供轻量诊断，
无需运行完整 LSP。

### 2.1 工具

| 工具 | 用途 |
| --- | --- |
| `codelens-diagnose` | 语法/语义诊断，返回错误列表（支持 TS/JS/Python/Rust/Go/C/C++/Java/C#/Ruby/PHP 等） |
| `codelens-find_definition` | 查找符号定义位置 |
| `codelens-find_references` | 查找符号在文件内的引用位置 |
| `codelens-file_outline` | 获取文件符号大纲（函数/类/变量等） |

### 2.2 使用示例

```text
# 修改前检查语法
codelens-diagnose filePath=src/renderer/app.tsx
→ 返回 errors: [{message, line, column, severity}]

# 理解文件结构
codelens-file_outline filePath=src/main/app/bootstrap.ts
→ 顶层符号列表（函数/类/常量）

# 跳转定义（配合 filesystem-read 使用）
codelens-find_definition filePath=src/main/native/types.ts line=414 column=20
→ 符号名 + 定义位置
```

### 2.3 注意事项

- `find_definition`/`find_references` 的定位基于**行号 + 列号**，先用
  `filesystem-read` 确定目标符号的位置再调用；
- 诊断是静态语义分析（oxc/tree-sitter），可能与实际编译器行为有细微
  差异；需要权威结果时运行 `tsc --noEmit` / `cargo check` 等真实编译。

## 3. 典型协作流程

```text
1. 理解项目   → codelens-file_outline + filesystem-read 读关键文件
2. 定位问题   → grep-search（关键词）或 codebase-search（语义）
3. 检查修改   → codelens-diagnose 快速发现语法/未引用错误
4. 正式验证   → 项目构建命令（tsc / cargo check / npm run check）
```

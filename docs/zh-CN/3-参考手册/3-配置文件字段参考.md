# 3-配置文件字段参考（Config File Field Reference）

本文档列出 `~/.snow/` 下全部配置文件的字段结构，供手动编辑或通过
`config` 工具读写时核对。`config` 工具的白名单与本文档保持一致：
文件型配置写后**可能需要重启应用或 UI 重存生效**（`settings.mcpServers`
除外——它自动同步应用数据库立即生效）。

> 各文件的读写方式（`config-get`/`config-set` 的 scope 名）见
> [2-内置工具参考](./2-内置工具参考.md) 的「支持的配置域」。

## 1. settings.json（scope: `settings`）

与 Snow CLI 共享的全局配置文件。顶层字段见
[1-settings.json配置参考](./1-settings.json配置参考.md)：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `mcpServers` | object | 全局 MCP 服务器，键为服务器名 |
| `codebase` | object | 代码库语义搜索配置 |
| `sensitiveCommands` | array | 敏感命令拦截规则 |
| `yoloMode` | boolean | 无确认模式 |
| `planMode` | boolean | 计划模式 |
| `vulnerabilityHuntingMode` | boolean | 漏洞狩猎模式 |
| `toolSearchEnabled` | boolean | 工具搜索开关 |
| `hybridCompressEnabled` | boolean | 混合压缩开关 |
| `teamMode` | boolean | 团队模式 |
| `goal` | object | Goal 模式配置（`defaultTokenBudgetM`：默认 token 预算，单位百万） |
| `ultraTodoEnabled` | boolean | 超长 TODO 列表开关 |

## 2. config.json（scope: `snowcfg`）

API 密钥与模型配置，统一保存在 `snowcfg` 对象下（与 Snow CLI 共享）。

| 字段 | 类型 | 敏感 | 说明 |
| --- | --- | --- | --- |
| `baseUrl` | string | | 主服务端点地址 |
| `baseUrlMode` | string | | `auto` 自动 / `custom` 手动 |
| `apiKey` | string | 🔒 | 主服务商密钥 |
| `requestMethod` | string | | 请求方法，如 `chat` |
| `advancedModel` | string | | 复杂任务模型 |
| `basicModel` | string | | 轻量任务模型 |
| `supportsVision` | boolean | | 主模型是否支持视觉 |
| `visionBaseUrl` | string | | 视觉服务端点 |
| `visionBaseUrlMode` | string | | 视觉端点模式 |
| `visionApiKey` | string | 🔒 | 视觉服务密钥 |
| `visionRequestMethod` | string | | 视觉请求方法 |
| `visionModel` | string | | 视觉模型名 |
| `maxContextTokens` | integer | | 最大上下文 token 数 |
| `maxTokens` | integer | | 单次生成最大 token 数 |
| `showThinking` | boolean | | 是否展示思考过程 |
| `streamIdleTimeoutSec` | integer | | 流式响应空闲超时（秒） |
| `maxRetries` | integer | | 请求最大重试次数 |
| `retryDelayMs` | integer | | 重试间隔（毫秒） |
| `enableAutoCompress` | boolean | | 自动压缩开关 |
| `autoCompressThreshold` | integer | | 自动压缩阈值（百分比） |
| `toolResultTokenLimit` | integer | | 工具结果写入上下文的 token 上限 |
| `anthropicBeta` | boolean | | Anthropic Beta 头开关 |
| `streamingDisplay` | boolean | | 流式显示开关 |
| `systemPromptId` | string | | 当前系统提示词 id |
| `customHeadersSchemeId` | string | | 当前自定义请求头方案 id |
| `anthropicCacheTTL` | string | | Anthropic 缓存 TTL，如 `5m` |
| `responsesReasoning` | object | | Responses 推理配置（`{enabled, effort}`） |
| `responsesVerbosity` | string | | Responses 输出详细度，如 `medium` |
| `responsesFastMode` | boolean | | Responses 快速模式 |
| `chatThinking` | object | | 思考强度配置（`{enabled, reasoning_effort}`） |

## 3. proxy-config.json（scope: `proxy`）

代理与浏览器配置。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `enabled` | boolean | 代理开关 |
| `host` | string | 代理主机，如 `127.0.0.1` |
| `port` | integer | 代理端口，如 `7890` |
| `searchEngine` | string | 搜索服务商，如 `bing` / `duckduckgo` |
| `browserPath` | string | 浏览器可执行文件路径 |
| `browserDebugPort` | integer | 浏览器调试端口 |

## 4. active-profile.json（scope: `app`）

当前生效的 API 档案。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `activeProfile` | string | 当前生效的档案名 |

## 5. custom-headers.json（scope: `custom-headers`）

自定义请求头方案（🔒 读取时脱敏）。

| 字段 | 类型 | 敏感 | 说明 |
| --- | --- | --- | --- |
| `active` | string | | 当前激活的方案 id |
| `schemes` | array | 🔒 | 方案数组，元素：`{id, name, headers, createdAt}`；`headers` 为 `{请求头名: 值}` 映射（可能含 `Authorization` 等敏感头） |

## 6. system-prompt.json（scope: `system-prompt`）

系统提示词库（🔒 读取时脱敏）。

| 字段 | 类型 | 敏感 | 说明 |
| --- | --- | --- | --- |
| `active` | array | | 激活的提示词 id 列表 |
| `prompts` | array | 🔒 | 提示词数组，元素：`{id, name, content, createdAt}` |

## 7. theme.json（scope: `theme`）

界面主题配置。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `theme` | string | 主题名，如 `custom` |
| `simpleMode` | boolean | 简洁模式 |
| `diffOpacity` | number | Diff 视图不透明度（浮点，如 `0.62`） |
| `toolDisplayMode` | string | 工具调用显示模式，如 `full` |
| `thinkDisplayMode` | string | 思考内容显示模式 |
| `subAgentDisplayMode` | string | 子代理显示模式，如 `slots` |
| `toolIcons` | object | 工具图标映射（`{工具名: 图标字符}`） |
| `customColors` | object | 自定义配色 |

## 8. language.json（scope: `language`）

界面语言。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `language` | string | 语言代码，如 `zh` / `en` |

## 9. permissions.json（scope: `permissions`）

工具授权配置。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `alwaysApprovedTools` | array | 免确认工具名列表（如 `["terminal-execute", "filesystem-read"]`） |

## 10. lsp-config.json（scope: `lsp-config`）

LSP 服务器配置。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `schemaVersion` | integer | 结构版本 |
| `servers` | object | 语言服务器映射，键为语言（如 `typescript`），值：`{command, args, fileExtensions, installCommand, initializationOptions}` |

## 11. buddy.json（scope: `buddy`）

应用吉祥物（伙伴）配置。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `version` | integer | 结构版本 |
| `companion` | object | 伙伴外观/性格配置（`{rarity, species, name, personality, stats, ...}`） |
| `muted` | boolean | 是否静音 |

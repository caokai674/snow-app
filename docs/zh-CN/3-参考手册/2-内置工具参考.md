# 2-内置工具参考

Snow App 内置一套 MCP 工具，供 AI Agent 执行文件操作、终端命令、
网络搜索、浏览器自动化等任务。本文列出全部内置服务器与工具。

## 1. 工具命名规则

内置工具全名为 `{服务器id}-{工具名}`，例如 `filesystem-read`。
部分服务器 id 包含 `-`（如 `user-interaction`），解析工具名时按
内置服务器列表做**最长前缀匹配**消除歧义。

## 2. 服务器总览

按注册顺序列出：

| 服务器 id | 说明 |
| --- | --- |
| `filesystem` | 本地文件读写（read / replace_edit / create） |
| `bash` | 终端命令执行 |
| `todo` | 会话任务清单管理 |
| `grep` | 文件内容搜索（ripgrep） |
| `websearch` | 网络搜索与网页抓取 |
| `browser` | 内置浏览器自动化（嵌入式 Electron 浏览器） |
| `user-interaction` | 向用户提问（阻塞式交互） |
| `sub-agents` | 激活子代理独立执行任务 |
| `codebase` | 代码库语义搜索（嵌入索引） |
| `codelens` | 代码诊断与符号定位 |
| `app-control` | 应用控制（备忘录 / 模式 / 设置页 / 定时任务 / 项目） |
| `config` | 全局配置文件读写（settings/snowcfg/proxy/app） |
| `skills` | 技能（Skill）加载与执行 |
| `skills-config` | 技能管理（列表现状 / 开关 / GitHub 安装与卸载） |

## 3. 工具明细

### filesystem

| 工具全名 | 用途 | 关键参数 |
| --- | --- | --- |
| `filesystem-read` | 读取文件内容（支持文本、图片、Office 文档） | `filePath`、`startLine`、`endLine` |
| `filesystem-replace_edit` | 模糊搜索替换编辑 | `filePath`、`searchContent`、`replaceContent`、`occurrence` |
| `filesystem-create` | 创建新文件（自动创建父目录） | `filePath`、`content`、`overwrite` |

### bash

| 工具全名 | 用途 | 关键参数 |
| --- | --- | --- |
| `bash-terminal-execute` | 执行终端命令（构建、测试、包管理等） | `command`、`description`、`workingDirectory`、`timeout` |

### todo

| 工具全名 | 用途 | 关键参数 |
| --- | --- | --- |
| `todo-todo-manage` | 会话任务清单管理（增删改查） | `action`、`content`、`sessionId`、`status`、`todoId`、`parentId` |

### grep

| 工具全名 | 用途 | 关键参数 |
| --- | --- | --- |
| `grep-search` | 使用 ripgrep 搜索文件内容 | `pattern`、`path`、`fileGlob`、`caseSensitive`、`isRegex`、`maxResults` |

### websearch

| 工具全名 | 用途 | 关键参数 |
| --- | --- | --- |
| `websearch-websearch-search` | 网络搜索，返回结果列表 | `query`、`maxResults` |
| `websearch-websearch-fetch` | 抓取并阅读网页全文或图片 | `url`、`maxLength`、`isUserProvided`、`userQuery` |

### browser

| 工具全名 | 用途 | 关键参数 |
| --- | --- | --- |
| `browser-create` | 创建嵌入式浏览器实例 | `url` |
| `browser-navigate` | 导航到指定 URL | `url`、`timeoutMs`、`instanceId` |
| `browser-click` | 以真实鼠标事件点击页面元素 | `selector`、`text`、`exact`、`instanceId` |
| `browser-screenshot` | 截取页面为 PNG | `fullPage`、`instanceId` |
| `browser-devtools` | 查看页面元数据与控制台信息 | `action`、`instanceId` |
| `browser-close` | 关闭浏览器标签页 | `instanceId` |
| `browser-focus` | 切换到指定标签页 | `instanceId` |
| `browser-list` | 列出所有打开的标签页 | — |

### user-interaction

| 工具全名 | 用途 | 关键参数 |
| --- | --- | --- |
| `user-interaction-askUserQuestion` | 向用户提问（阻塞式交互，需单独调用） | `question`、`options` |

### sub-agents

| 工具全名 | 用途 | 关键参数 |
| --- | --- | --- |

### codebase

| 工具全名 | 用途 | 关键参数 |
| --- | --- | --- |
| `codebase-search` | 代码库语义搜索（基于嵌入索引） | `pattern`、`path`、`fileGlob`、`maxResults` |

### codelens

| 工具全名 | 用途 | 关键参数 |
| --- | --- | --- |
| `codelens-diagnose` | 运行代码诊断，返回语法/语义错误 | `filePath` |
| `codelens-find_definition` | 查找符号定义位置 | `filePath`、`line`、`column` |
| `codelens-find_references` | 查找符号引用位置 | `filePath`、`line`、`column` |
| `codelens-file_outline` | 获取文件符号大纲 | `filePath` |

### app-control

| 工具全名 | 用途 | 关键参数 |
| --- | --- | --- |
| `app-control-createMemo` | 创建备忘录（笔记） | `content` |
| `app-control-setMode` | 启用/禁用 Plan Mode 或 Goal Mode | `mode`、`enabled` |
| `app-control-openSettings` | 打开指定设置页 | `page` |
| `app-control-createScheduledTask` | 创建定时任务 | `name`、`prompt`、`schedule` |
| `app-control-createProject` | 创建项目（工作区目录） | `name`、`parentPath` |
| `app-control-requestApproval` | 请求用户确认计划摘要（仅 Plan Mode 下暴露） | `planSummary` |

### config

| 工具全名 | 用途 | 关键参数 |
| --- | --- | --- |
| `config-list` | 列出可管理配置域（settings/snowcfg/proxy/app）与各域键；传 `scope` 查看单域详情与当前值（敏感键脱敏） | `scope` |
| `config-get` | 读取指定域/键的值；`apiKey`/`visionApiKey` 等敏感键强制脱敏 | `scope`、`key` |
| `config-set` | 写入指定域/键（白名单 + 类型校验 + 自动备份 + 原子写）；`settings.mcpServers` 自动同步应用数据库立即生效 | `scope`、`key`、`value` |
| `config-delete` | 删除指定域/键 | `scope`、`key` |

支持的配置域：

| 域 | 文件 | 主要键 |
| --- | --- | --- |
| `settings` | `~/.snow/settings.json` | `mcpServers`、`codebase`、`sensitiveCommands`、`yoloMode`、`planMode` 等 |
| `snowcfg` | `~/.snow/config.json`（`snowcfg` 对象） | `baseUrl`、`apiKey`（敏感）、`advancedModel`、`maxTokens` 等 |
| `proxy` | `~/.snow/proxy-config.json` | `enabled`、`host`、`port`、`searchEngine`、`browserPath`、`browserDebugPort` |
| `app` | `~/.snow/active-profile.json` | `activeProfile` |

### skills

| 工具全名 | 用途 | 关键参数 |
| --- | --- | --- |
| `skills-skill-execute` | 加载并执行指定技能 | `skill` |

### skills-config

| 工具全名 | 用途 | 关键参数 |
| --- | --- | --- |
| `skills-config-list` | 列出可用技能与 GitHub 已装记录；不传 `projectId` 时 `enabled` 为 SKILL.md frontmatter 的 `enable` 字段值，传 `projectId` 时为项目视角（四目录合并，`enabled` = 项目 DB 覆盖优先于 frontmatter，另有 `defaultEnabled` = frontmatter 值） | `projectId` |
| `skills-config-setEnabled` | 切换技能开关：不传 `projectId` 改写 SKILL.md frontmatter 的 `enable` 字段（与 UI 开关同源）；传 `projectId` 写入应用数据库项目级覆盖（立即生效且优先于 frontmatter） | `projectId`、`skillId`、`enabled` |
| `skills-config-installGithub` | 从 GitHub 仓库安装技能（`url` 支持完整 URL 与 `owner/repo` 简写，可带 `@branch` 与 `:sub/dir`；`location` 为 `global`/`project`，项目安装需 `projectId`）；元数据记录在 `~/.snow/skills-registry.json` | `url`、`location`、`projectId` |
| `skills-config-uninstall` | 卸载 GitHub 安装的技能（仅限 registry 中的技能；手动放置或应用自带的技能需删除目录） | `skillId`、`projectId` |

> 注意：frontmatter 中控制开关的字段名是 `enable`（不是 `enabled`）。

## 4. 特殊说明

**`app-control-openSettings` 的 `page` 参数合法值：**

| page 值 | 对应设置页 |
| --- | --- |
| `api-settings` | API 设置 |
| `proxy-browser-settings` | 代理与浏览器 |
| `codebase-settings` | 代码库设置 |
| `system-prompt-settings` | 系统提示词 |
| `custom-headers-settings` | 自定义请求头 |
| `mcp-settings` | MCP 设置 |
| `skills-settings` | Skills 设置 |
| `sub-agent-settings` | 子代理设置 |
| `sensitive-command-settings` | 敏感命令 |
| `hooks-settings` | Hooks 设置 |
| `theme-settings` | 主题设置 |
| `terminal-settings` | 终端设置 |
| `keyboard-shortcuts-settings` | 键盘快捷键 |
| `privacy-settings` | 隐私设置 |
| `usage-settings` | 用量设置 |
| `system-logs` | 系统日志 |

**其他说明：**

- `app-control-requestApproval` 仅在 Plan Mode 启用时暴露；
- `skills-skill-execute` 动态加载 `~/.snow/skills` 与项目 `.snow/skills`
  下已启用的技能。

## 5. 与外部 MCP 工具的区别

外部 MCP 服务器工具由用户在 **MCP 设置** 中添加
（见 [2-使用指南/1-配置MCP服务器](../2-使用指南/1-配置MCP服务器.md)），
工具名前缀为服务器名（如 `dbx-search_context`），与内置工具通过
内置服务器列表前缀匹配的方式区分。

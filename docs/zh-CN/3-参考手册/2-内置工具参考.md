# 2-内置工具参考

Snow App 内置一套 MCP 工具，供 AI Agent 执行文件操作、终端命令、
网络搜索、浏览器自动化等任务。本文列出全部内置服务器与工具。

## 1. 工具命名规则

内置工具全名为 `{服务器id}-{工具名}`，例如 `filesystem-read`。
部分服务器 id 包含 `-`（如 `user-interaction`），解析工具名时按
内置服务器列表做**最长前缀匹配**消除歧义。

## 2. 服务器总览

按注册顺序列出：

| 服务器 id          | 说明                                                                                    |
| ------------------ | --------------------------------------------------------------------------------------- |
| `filesystem`       | 本地文件读写（read / replace_edit / create）                                            |
| `bash`             | 终端命令执行                                                                            |
| `todo`             | 会话任务清单管理                                                                        |
| `grep`             | 文件内容搜索（ripgrep）                                                                 |
| `websearch`        | 网络搜索与网页抓取                                                                      |
| `browser`          | 内置浏览器自动化（嵌入式 Electron 浏览器）                                              |
| `user-interaction` | 向用户提问（阻塞式交互）                                                                |
| `sub-agents`       | 激活子代理独立执行任务                                                                  |
| `codebase`         | 代码库语义搜索（嵌入索引）                                                              |
| `codelens`         | 代码诊断与符号定位                                                                      |
| `app-control`      | 应用控制（备忘录 / 模式 / 设置页 / 定时任务 / 项目）                                    |
| `config`           | 全局配置读写（文件：settings/snowcfg/proxy/app；数据库：subAgents/hooks；委托：skills） |
| `skills`           | 技能（Skill）加载与执行                                                                 |
| `imagegen`         | AI 图像生成与编辑（OpenAI / Gemini 多渠道；**所有渠道均未配置时按需隐藏**）        |

### config

| 工具全名        | 用途                                                                                                                                                                                                                | 关键参数                             |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| `config-list`   | 列出可管理配置域（settings/snowcfg/proxy/app/custom-headers/system-prompt/theme/language/permissions/lsp-config/buddy/subAgents/hooks/skills/logs/imagegen）与各域键；传 `scope` 查看单域详情与当前值（敏感键脱敏） | `scope`、`projectId`                 |
| `config-get`    | 读取指定域/键的值；`apiKey`/`visionApiKey` 等敏感键强制脱敏；`subAgents`/`hooks` 域直接读应用数据库                                                                                                                 | `scope`、`key`、`projectId`          |
| `config-set`    | 写入指定域/键（白名单 + 类型校验 + 自动备份 + 原子写）；`settings.mcpServers` 自动同步应用数据库立即生效；`subAgents`/`hooks` 域直接写应用数据库立即生效                                                            | `scope`、`key`、`value`、`projectId` |
| `config-delete` | 删除指定域/键；`subAgents`/`hooks` 域直接删除数据库记录                                                                                                                                                             | `scope`、`key`、`projectId`          |

> **结构校验**：`settings.codebase`、`custom-headers.schemes`、
> `system-prompt.prompts`、`lsp-config.servers` 在写入时会做**嵌套结构深度
> 校验**（对已知字段逐一检查类型，如 `codebase.embedding.dimensions` 必须是
> 数字），防止 agent 写坏内部字段；未知字段放行以保持前向兼容。
>
> **项目级 settings**：给 `settings` scope 的 `mcpServers` / `sensitiveCommands`
> 传 `projectId` 可读写**项目级**配置（应用数据库，立即生效，与 UI 项目级设置
> 同源）：`mcpServers` 为全量替换（value 为 `{name: {type,url,command,args,env,headers,enabled,timeoutMs}}`）；
> `sensitiveCommands` 为全量替换（value 为数组，元素 `{commandId, pattern, description, enabled}`，
> commandId 匹配全局规则时作为 enabled 覆盖，其余为项目自定义规则）；
> 其余键不支持 projectId（会明确报错）。

数据库型配置域（写入应用 SQLite 数据库，与 UI 设置面板同源，立即生效）：

| 域          | key                                                                                                             | value                                                                                                                                                                                                                                           | 说明                                                                                                                                                                                                                                                                                          |
| ----------- | --------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `subAgents` | `agentId`                                                                                                       | `{name, description?, systemPrompt?, toolsJson?, configProfile?}`                                                                                                                                                                               | 创建/更新子代理；`toolsJson` 接受 JSON 字符串或工具名数组；内置 `agent_general` 不可修改/删除；不传 `projectId` 为全局，传入则为项目级                                                                                                                                                        |
| `hooks`     | `hookType`                                                                                                      | `{rules: [{description, matcher?, hooks: [{type, command?, prompt?, content?, timeout?, enabled?}]}]}`                                                                                                                                          | 配置生命周期 hook；不传 `projectId` 为全局，传入则为项目级（项目级覆盖全局）                                                                                                                                                                                                                  |
| `imagegen`  | `openai` / `gemini`（省略 key 返回全部；无 key 时返回 `{channels, maxConcurrentImages, timeoutSecs}` 完整设置） | 渠道字段：`{enabled, baseUrl?, apiKey?, model?, defaultSize?, defaultQuality?, outputFormat?, webSearch?, defaultStream?}`；顶层另有全局字段 `maxConcurrentImages`（最大并发生成数 1-8）与 `timeoutSecs`（生图请求超时，秒，60-3600，默认 300） | 图像生成多渠道设置（应用数据库 `system_settings` 表，与设置面板同源）；`config-set` 部分更新自动合并（未提供的字段保留原值，`maxConcurrentImages` 与 `timeoutSecs` 也会保留，除非显式提供新值）；`apiKey` 读取一律脱敏（如 `sk-e****7890`）；`config-delete` 清空后生图工具从 AI 工具列表隐藏 |

委托型配置域（复用技能管理服务 SkillsConfigService 的实现，存储机制与 UI 一致）：

只读日志域（供 agent 自主分析应用异常，无需人工看日志）：

| 域     | key                                                                                                    | 说明                                                                                                                                                                                                                                                                                           |
| ------ | ------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `logs` | 日志文件名（如 `2026-08-03-error.log`）或级别简写（`error`/`warn`/`info`/`debug`，读取今天的对应文件） | `config-list logs` 返回 `~/.snow/log` 下全部日志文件（按日期倒序，含大小/级别）与最近错误文件摘要；`config-get logs` 读取文件尾部内容（可选 `limit` 控制行数，默认 200、最大 2000，环形缓冲防大文件全量加载）；`config-set logs` 只读；`config-delete logs` 仅接受精确文件名删除（防路径穿越） |

### imagegen

| 工具全名            | 用途                                                                                                                              | 关键参数         |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| `imagegen-generate` | 文生图 / 图生图编辑（OpenAI + Gemini Nano Banana 多渠道，独立于对话 API 配置；**所有渠道均未配置时工具从 AI 工具列表隐藏**） | 见下方 18 参数表 |

`imagegen-generate` 完整参数：

| 参数                | 类型           | 说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`            | string（必填） | 生成描述；提供参考图时为编辑指令                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `images`            | array          | 参考图 `[{data, mimeType}]`（base64，不含 `data:` 前缀；兼容带前缀的 data URL）或 `[{path, mimeType}]`（upload 目录下的相对路径，来自纯文本主模型消息中的 `[Reference image #N for imagegen-generate: ...]` 引用块，服务端自动读取文件转 base64，无需复制大段数据）；`path` **仅限 upload 目录内**（拒绝绝对路径与 `..` 穿越）；图生图/编辑用；服务端上限 **14 张**、单张 ≤20MB（工具描述引导 AI 单次 ≤5 张，兼容部分服务商更严格的限制）；OpenAI 走 `/images/edits`、Gemini 走 `inlineData` |
| `model`             | string         | 覆盖设置中的模型；OpenAI：`gpt-image-1`/`gpt-image-2`/`dall-e-3`；Gemini：`gemini-3.1-flash-image`（Nano Banana 2）/`gemini-3.1-flash-lite-image`（Lite）/`gemini-3-pro-image`（Pro）/`gemini-2.5-flash-image`（旧版）。**能力规则（不支持的请求会 400）**：`dall-e-3` 仅文生图（不接受参考图）且每次仅生成 1 张；`imagen-*` 同样仅文生图                                                                                                                                                    |
| `provider`          | enum           | `auto`（默认，按配置推导）/ `openai` / `gemini`，后端切换                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `size`              | string         | OpenAI：`1024x1024`、`1024x1536`、`1536x1024` 等；Gemini：`1K`/`2K`/`4K`（imageSize）或 `16:9`、`1:1`、`9:16` 等（aspectRatio）                                                                                                                                                                                                                                                                                                                                                              |
| `quality`           | enum           | `low` / `medium` / `high` / `auto`；OpenAI 仅 gpt-image 系列生效，Gemini 仅接受 `low`/`medium`/`high`（`auto` 被忽略）                                                                                                                                                                                                                                                                                                                                                                       |
| `outputFormat`      | enum           | OpenAI：`png`（默认）/ `jpeg` / `webp`；dall-e 与 Gemini 忽略                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `outputCompression` | number         | OpenAI JPEG/WebP 压缩率 0-100                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `n`                 | number         | 一次生成张数（默认 1，最大 4）；`dall-e-3` 恒为 1（自动收敛）                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `personGeneration`  | enum           | Gemini：`dont_allow`（默认）/ `allow_all` / `allow_adult`                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `webSearch`         | boolean        | Gemini 联网搜索（Grounding with Google Search），默认取设置                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `stream`            | boolean        | 流式预览（OpenAI `partial_images` SSE / Gemini `streamGenerateContent`），默认取设置；dall-e 与图生图忽略                                                                                                                                                                                                                                                                                                                                                                                    |
| `inputFidelity`     | enum           | OpenAI 编辑保真度：`low` / `high` / `auto`（默认）；`gpt-image-2` 不支持（恒为高保真）                                                                                                                                                                                                                                                                                                                                                                                                       |
| `background`        | enum           | OpenAI：`opaque`（默认）/ `transparent` / `auto`；透明背景需模型支持（`gpt-image-2` 等不支持时自动降级为 `opaque`）                                                                                                                                                                                                                                                                                                                                                                          |
| `moderation`        | enum           | OpenAI：`auto`（默认）/ `low`（更宽松过滤）                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `seed`              | number         | 确定性种子，复现结果                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `thinkingLevel`     | enum           | Gemini 3.1 Flash Image：`minimal`（默认，快）/ `high`（质量更高，慢）                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `imageSearch`       | boolean        | Gemini 3.1 Flash Image：Google Image Search 联网参考（需展示搜索建议）                                                                                                                                                                                                                                                                                                                                                                                                                       |

> **配置与暴露规则**：渠道需 `enabled` + `apiKey` + `model` 三者齐备才算可用；
> 多个渠道可同时启用，AI 按请求选择（未指定渠道时按渠道顺序取第一个可用渠道，也可传 `provider` 指定）；
> 均未配置时 `imagegen-generate` 从模型工具列表隐藏。
> 不支持的模型能力会在**发送前**自动校验（`dall-e-3`/`imagen-*` 传参考图
> 本地拦截并提示换模型；`dall-e-3` 的 `n` 自动收敛为 1）；仍出现的上游 400
> 会附带具体修复提示（多图数量 / 图像输入 / 尺寸 / 质量）。
> 图形界面配置见 [2-使用指南/9-图像生成](../2-使用指南/9-图像生成.md)；
> 也可通过 `config` 工具的 `imagegen` scope 读写（见上文，apiKey 脱敏）；
> 一次请求多张时并行生成，受设置中的「最大并发生成数」限制（1-8，默认 4），超出排队、完成一张补一张。
> **Imagen 已弃用**：`imagen-*` 模型 2026-08-17 关停，请用 Nano Banana 系列。

- `app-control-requestApproval` 仅在 Plan Mode 启用时暴露；
- `skills-skill-execute` 动态加载 `~/.snow/skills` 与项目 `.snow/skills`
  下已启用的技能。

## 5. 与外部 MCP 工具的区别

外部 MCP 服务器工具由用户在 **MCP 设置** 中添加
（见 [2-使用指南/1-配置 MCP 服务器](../2-使用指南/1-配置MCP服务器.md)），
工具名前缀为服务器名（如 `dbx-search_context`），与内置工具通过
内置服务器列表前缀匹配的方式区分。

# 数据存储位置参考

> 本文档基于 `native/src/storage/` 与 `src/main/` 源码整理，说明 Snow App 的所有数据写入位置，便于备份、迁移与排障。

## 存储架构总览

Snow App 的数据存储分为 **3 层**：

```
┌─────────────────────────────────────────────────────────┐
│ ① Rust 原生层（SQLite 数据库 + 应用资源文件）             │
│    ~/.snowapp/                                           │
├─────────────────────────────────────────────────────────┤
│ ② Electron 主进程层（userData + 全局配置）                │
│    %APPDATA%/Snow App/          （Windows）              │
│    ~/.snow/                     （全局 CLI 配置）         │
├─────────────────────────────────────────────────────────┤
│ ③ 项目工作区层                                            │
│    <workspace>/.snow/           （项目级配置与日志）      │
└─────────────────────────────────────────────────────────┘
```

---

## ① Rust 原生层：`~/.snowapp/`

存储目录由 `native/src/storage/paths.rs` 定义：`<home>/.snowapp`，通过 `dirs_next::home_dir()` 解析。数据库使用 **SQLite（rusqlite）+ WAL 模式**，连接配置见 `database.rs`（`journal_mode=WAL`、`synchronous=NORMAL`、5 秒 busy timeout）。

### 1.1 主数据库：`~/.snowapp/snowapp.db`

所有业务数据（会话、消息、配置、用量、备忘录、插件等）都在这一个 SQLite 文件中，共 21+ 张表：

| 表名 | 内容 |
|------|------|
| `system_settings` | 键值对全局设置（主题、隐私、快捷键、plan/goal/yolo 模式、请求日志开关、图像生成配置 `imagegen_settings` 等） |
| `api_configs` | API 密钥与模型配置（profile） |
| `system_prompts` | 系统提示词模板 |
| `custom_header_schemes` | 自定义请求头方案 |
| `workspace_directories` | 工作目录列表（含内置默认目录） |
| `mcp_server_configs` | MCP 服务器配置（全局） |
| `import_resources` / `import_resource_sources` | 第三方配置导入的资源记录与来源 |
| `plugins` / `plugin_marketplaces` / `plugin_components` | 插件、插件市场与组件注册信息 |
| `sub_agent_configs` | 子代理配置 |
| `sensitive_command_configs` | 敏感命令规则 |
| `chat_conversations` | 会话列表（含 API profile、模式开关） |
| `sub_agent_sessions` | 子代理会话 |
| `chat_messages` | 聊天消息（含内联图片引用 `@@image:...@@`） |
| `todo_items` | TODO 任务项 |
| `usage_records` | 用量统计（token 消耗等） |
| `app_logs` | 应用日志（设置界面「系统日志」读取此表） |
| `memos` | 备忘录 |
| `codebase_embed_sessions` | 代码库嵌入（embedding）会话状态 |
| `codebase_embeddings_*` | 每个项目的代码向量索引（按项目动态建表） |

> 数据库存在 `DATABASE_PATH_CACHE` 一次性初始化（创建目录 → 建表 → 播种默认值），见 `storage/mod.rs::ensure_database_file`。迁移采用 pre/post schema 两阶段，见 `migrations.rs`。

### 1.2 应用资源目录

| 路径 | 内容 |
|------|------|
| `~/.snowapp/checkpoints/` | 会话文件变更检查点（`checkpoint.rs`，备份用户文件快照，排除 `.snow`/`.snowapp` 目录） |
| `~/.snowapp/backgrounds/` | 用户选择的主题背景图（复制后引用，`storage/mod.rs`） |
| `~/.snowapp/stream-cursors/` | 用户自定义流式光标 SVG |
| `~/.snowapp/upload/<YYYY-MM-DD>/` | 聊天内联图片（base64 落盘为 `<hash>.<ext>`，消息中存相对路径 `upload/<日期>/<文件名>`，见 `api/conversation/images.rs`） |
| `~/.snowapp/workspace/` | 内置默认工作目录（`source=builtin`，用于未添加任何目录时的会话挂载） |

## ② Electron 主进程层

### 2.1 userData：`%APPDATA%/Snow App/`（Windows）/ `~/Library/Application Support/Snow App/`（macOS）

应用名在 `bootstrap.ts` 中设置为 `Snow App`（appId `com.snow.app`）。

| 路径 | 内容 |
|------|------|
| `<userData>/window-state.json` | 窗口位置/尺寸/最大化状态（`app/windowState.ts`） |
| `<userData>/plugins/` | 插件运行时的隔离存储（`pluginRuntimeManager.ts`，插件经 `SNOW_PLUGIN_STORAGE_PATH` 环境变量访问） |
| `<userData>/ssh-credentials` | SSH 凭据（`ssh/sshCredentials.ts`） |
| `<userData>/updates/` | 应用更新下载缓存（`updater/macUpdater.ts`） |

### 2.2 全局配置：`~/.snow/`

与 Snow CLI 共享的全局目录（`snowCli/paths.ts` 定义 `SNOW_CLI_CONFIG_DIR`）。

| 路径 | 内容 |
|------|------|
| `~/.snow/settings.json` | 全局设置（MCP、代理等；项目级同名文件覆盖） |
| `~/.snow/ROLE.md` | 全局角色定义（`personalizationHandlers.ts`） |
| `~/.snow/skills/` | 全局 Skills（应用内置 Skills 同步到此，`ensureBuiltinSkills.ts`） |
| `~/.snow/docs/` | 应用内置文档同步副本（升级时按版本整树覆盖） |
| `~/.snow/plugin-marketplaces/` | 插件市场缓存 |
| `~/.snow/plugins/marketplaces/` | 从市场安装的插件本体 |
| `~/.snow/codex-plugins.json` | Codex 兼容插件清单 |

### 2.3 其他

- `app.getPath("logs")/updater.log` — 更新器日志（macOS 更新流程）
- `logs:list` / `logs:clear` IPC — 读取的是数据库 `app_logs` 表

## ③ 项目工作区层：`<workspace>/.snow/`

| 路径 | 内容 |
|------|------|
| `<workspace>/.snow/settings.json` | 项目级设置（覆盖全局，`mcpSettings.ts` / `remoteWorkspaceCommand.ts`） |
| `<workspace>/.snow/skills/` | 项目级 Skills |
| `<workspace>/.snow/logs/` | bash 工具 `detach:true` 后台执行日志：`<name>-<timestamp>.log`（`mcp/servers/bash.rs`，`.snow` 已在 .gitignore） |

> `.snow` 目录被 .gitignore、checkpoint 扫描与 SSH 文件遍历统一排除。

## 各平台路径速查

| 数据 | Windows | macOS | Linux |
|------|---------|-------|-------|
| 主数据库 | `%USERPROFILE%\.snowapp\snowapp.db` | `~/.snowapp/snowapp.db` | `~/.snowapp/snowapp.db` |
| 应用资源 | `%USERPROFILE%\.snowapp\` | `~/.snowapp/` | `~/.snowapp/` |
| userData | `%APPDATA%\Snow App\` | `~/Library/Application Support/Snow App/` | `~/.config/Snow App/` |
| 全局配置 | `%USERPROFILE%\.snow\` | `~/.snow/` | `~/.snow/` |
| 项目配置 | `<workspace>\.snow\` | `<workspace>/.snow/` | `<workspace>/.snow/` |

## 备份与迁移建议

- **完整备份**：复制 `~/.snowapp/`（含 `snowapp.db`、`upload/`、`backgrounds/`、`checkpoints/`）与 `~/.snow/` 即可覆盖绝大部分数据。
- **聊天图片**：仅备份数据库会丢失内联图片，需连同 `~/.snowapp/upload/` 一起备份。
- **插件数据**：插件自身数据在 `<userData>/plugins/`，备份时可一并纳入。
- **跨平台迁移**：数据库路径是硬编码的 home 目录相对路径，直接复制三个目录即可；注意 Windows 路径反斜杠在消息内联图片引用中会被规范化为正斜杠。
